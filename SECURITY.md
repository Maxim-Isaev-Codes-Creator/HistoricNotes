# Безопасность и локальные данные

Кабинет хранит бумаги и подписи ящиков в IndexedDB данного браузера. Содержимое шифруется **до** записи. Пароль задаётся при первом запуске в конкретном профиле браузера; затем нужен для каждого нового сеанса. Общего сервера учётных записей и синхронизации нет.

## Шифрование

- Из пароля и случайной 16-байтовой соли хранилища Web Crypto получает 256-битный ключ через PBKDF2-HMAC-SHA-256 с 600 000 итераций. Пароль и открытый ключ не записываются на диск приложением.
- Для каждой новой операции шифрования создаются отдельные случайные 16-байтовая соль и 12-байтовый IV. Из основного ключа и этой соли через HKDF-SHA-256 получается отдельный ключ AES-256-GCM. Вместе с шифротекстом сохраняются только версия, соль и IV. Старые записи AES-GCM прежнего формата читаются после ввода правильного пароля; при следующем сохранении они переходят на новый формат.
- Тексты, заголовки и подписи ящиков шифруются. В открытом виде остаются случайный идентификатор записи, параметры шифрования и настройки интерфейса (например, громкость). Копирование по кнопке «Сохранить» помещает открытый текст в буфер обмена по явному действию пользователя.
- При запирании интерфейс удаляет открытые документы из своих структур и DOM и сбрасывает ссылки на криптографические ключи. JavaScript и браузер не гарантируют мгновенного стирания всех копий из памяти.

## Сеть и разрешения

Рабочие документы не отправляются по сети. Приложение не использует камеру, микрофон, геолокацию, Bluetooth, USB или File System Access API. Сервер задаёт `Permissions-Policy` с запретом этих возможностей.

CSP документа: `default-src 'none'`, `script-src 'self'`, `style-src 'self'`, `img-src 'self' data:`, `font-src 'none'`, `connect-src 'none'`, `worker-src 'self'`, `manifest-src 'self'`, `object-src 'none'`, `frame-src 'none'`, `base-uri 'none'`, `form-action 'none'`, `frame-ancestors 'none'`. Небольшие SVG-фактуры в локальном CSS требуют `img-src data:`. Service Worker имеет отдельную политику `connect-src 'self'`: только ему нужно получать файлы оболочки приложения при установке и обновлении. Обычные документы не проходят через Service Worker. Локальные модули и стили загружаются с того же источника.

`frame-ancestors` действует только в HTTP-заголовке, поэтому при размещении на другом сервере нужно перенести заголовки из `dev-server.mjs`. Для установки PWA и Web Crypto вне localhost нужен HTTPS. Приватный репозиторий GitHub содержит код, но сам по себе не размещает приложение для пользователей.

## Границы защиты

Шифрование не защищает открытый документ от вредоносного расширения браузера, заражённой системы, доступа к разблокированному экрану или изменённого кода приложения при обновлении. Слабый пароль можно подбирать по копии зашифрованного хранилища. Утрата пароля или очистка данных сайта может безвозвратно лишить доступа к бумагам. Буфер обмена контролируется устройством, а не приложением. PWA не обеспечивает абсолютную изоляцию от операционной системы.
